# Algoritmos e Pensamento Computacional — ADS

Repositório destinado ao armazenamento dos exercícios, práticas e atividades desenvolvidos durante a disciplina **Algoritmos e Pensamento Computacional**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

## Sobre a disciplina

A disciplina tem como objetivo desenvolver o raciocínio lógico e a capacidade de analisar, estruturar e solucionar problemas computacionais por meio de algoritmos e programação.

Durante o curso, os conceitos são aplicados utilizando a **Linguagem C**, permitindo praticar a construção de programas e aprofundar os fundamentos de programação.

* **Aulas** — organizam os conteúdos e atividades de cada aula.

## Objetivos de estudo

Ao longo da disciplina, este repositório será utilizado para praticar:

* Raciocínio lógico;
* Pensamento computacional;
* Construção e interpretação de algoritmos;
* Resolução de problemas;
* Estruturas fundamentais da programação;
* Desenvolvimento de programas em C;
* Análise e depuração de código.

## Compilação e execução

Os programas em C podem ser compilados utilizando um compilador compatível, como o **GCC**.

Exemplo:

```bash
gcc exercicio-01.c -o exercicio-01
```

Para executar:

### Windows

```bash
exercicio-01.exe
```

### Linux / macOS

```bash
./exercicio-01
```
